# Firmen-Server Handbuch

Dieses Verzeichnis simuliert die Infrastruktur der Firma.

## Zuständigkeiten
- `users/`: Enthält die Akten der angelegten Mitarbeiter.
- `backups/`: Speicherort für die System-Backups.
- `inventory/`: Liste aller aktiven Firmen-Server.
- `scripts/`: Automatisierungs-Werkzeuge für Admins.
