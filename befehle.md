# 📁 Allgemeine Linux-Befehle

Hier sammeln wir die Basis-Befehle für die Navigation im Terminal.

## 🧭 Navigation
* `pwd` — Zeigt den aktuellen Ordnerpfad an (*Print Working Directory*).
* `cd <pfad>` — Wechselt in einen anderen Ordner (*Change Directory*).

## 📄 Dateien verwalten
* `mkdir <name>` — Erstellt einen neuen Ordner.
* `touch <datei>` — Erstellt eine neue, leere Datei.
* `ls` — Listet alle Dateien im aktuellen Ordner auf.

# 📁 Allgemeine Linux-Befehle & Navigation

Hier sammeln wir die wichtigsten Basis-Befehle für die Dateiverwaltung und Bewegung im Terminal.

---
## 🧭 Navigation im Dateisystem
* `pwd` — Zeigt den aktuellen Ordnerpfad an (*Print Working Directory*).
* `ls` — Listet alle Dateien und Ordner im aktuellen Verzeichnis auf.
* `ls -la` — Zeigt alle Dateien an, inklusive versteckter Dateien und Details.
* `cd <ordner>` — Wechselt in den angegebenen Unterordner (*Change Directory*).
* `cd ..` — Geht eine Verzeichnisebene nach oben (in den Eltern-Ordner).
* `cd ~` — Springt sofort zurück in das persönliche Hauptverzeichnis (Home).

---

## 📄 Dateien & Ordner verwalten
* `mkdir <name>` — Erstellt einen neuen Ordner (*Make Directory*).
* `touch <datei>` — Erstellt eine neue, komplett leere Datei.
* `nano <datei>` — Öffnet eine Datei im Terminal-Editor zum Schreiben.
* `cat <datei>` — Gibt den gesamten Inhalt einer Datei direkt im Terminal aus.
* `less <datei>` — Öffnet eine Datei in einer scrollbaren Lese-Ansicht (Beenden mit `Q`).

---

## ✂️ Verschieben, Kopieren & Löschen
* `mv <alt> <neu>` — Benennt eine Datei/einen Ordner um oder verschiebt sie (*Move*).
* `cp <quelle> <ziel>` — Kopiert eine Datei an einen anderen Ort (*Copy*).
* `cp -r <quelle> <ziel>` — Kopiert einen gesamten Ordner inklusive Inhalt.
* `rm <datei>` — Löscht eine Datei dauerhaft (*Remove* – kein Papierkorb!).
* `rmdir <ordner>` — Löscht einen komplett leeren Ordner.
* `rm -r <ordner>` — Löscht einen Ordner inklusive aller enthaltenen Dateien.
